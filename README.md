# CarRental — сервис аренды автомобилей

Frontend MVP: веб-приложение для поиска и бронирования автомобилей в аренду.

## Идея

Пользователь выбирает автомобиль из каталога, указывает даты аренды и оформляет
бронирование онлайн — без звонков и визита в офис.

**Целевой пользователь:** мужчины и женщины 25–45 лет — горожане без личного авто,
командировочные и туристы, привыкшие решать задачи онлайн.

**Основная задача:** быстро найти свободный автомобиль на нужные даты, рассчитать
стоимость аренды и оформить бронь за пару минут.

## Страницы

| Экран | Адрес | Описание |
|---|---|---|
| Главная | `/` | Описание сервиса, кнопка перехода в каталог |
| Каталог автомобилей | `/cars` | Список авто с фильтром по классу |
| Карточка автомобиля | `/cars/:carId` | Характеристики авто (динамический маршрут) |
| Бронирование | `/booking` | Форма оформления брони |
| Мои бронирования | `/my-bookings` | Список броней со статусами |
| О сервисе | `/about` | Условия аренды и контакты |
| Страница 404 | любой несуществующий адрес | «Страница не найдена» |

## Установка и запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу http://localhost:5173

## Технологии

- **React 19** + **Vite**
- **React Router 7** — createBrowserRouter, Layout с Outlet, NavLink, useParams, useNavigate
- Моковые данные (`src/data/cars.js`) — перед интеграцией с бэкендом
